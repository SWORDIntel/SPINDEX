# AEGIS-005: Format Conversion & Abstraction Module (GDAL/OGR)

This module is developed to detect input vector formats and convert them to a standard interchange format like GeoJSON using GDAL/OGR.

This folder is the designated location for documentation and code artifacts specific to this module.
## Existing C Implementation Notes

Core C-level processing related to GeoJSON, which is a standard interchange format for this module, can be found in `SPINDEX/plugins/aegis_modules/geojson_processor.c` and `SPINDEX/plugins/aegis_modules/geojson_processor.h`.

# AEGIS-009: Unstructured Text Parsing (NLP/NER) Module

This module is developed to use NER (Named Entity Recognition) for extracting location names from text, integrating with the geocoding module.

This folder is the designated location for documentation and code artifacts specific to this module.
## Existing C Implementation

The C language implementation for the NLP/NER parsing capabilities of this module can be found in `SPINDEX/plugins/aegis_modules/nlp_ner_parser.c` and `SPINDEX/plugins/aegis_modules/nlp_ner_parser.h`.

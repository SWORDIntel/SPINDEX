# AEGIS-010: Geometric Validation Module

This module is developed to check for and optionally repair invalid geometries (e.g., using Shapely).

This folder is the designated location for documentation and code artifacts specific to this module.
## Existing C Implementation

The C language implementation for this module can be found in `SPINDEX/plugins/aegis_modules/geometric_validator.c` and `SPINDEX/plugins/aegis_modules/geometric_validator.h`.

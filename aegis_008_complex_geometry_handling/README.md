# AEGIS-008: Complex Geometry Handling Module

This module is developed to manage datasets with mixed geometry types based on configurable strategies (split, filter, reject).

This folder is the designated location for documentation and code artifacts specific to this module.
## Existing C Implementation

The C language implementation for this module can be found in `SPINDEX/plugins/aegis_modules/complex_geometry_handler.c` and `SPINDEX/plugins/aegis_modules/complex_geometry_handler.h`.
